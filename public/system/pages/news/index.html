WannaSmile 2.4.0 – Nexus

Nexus release notes · planned for November 13, 2026.

✨Nexus update overview

🌐

Domain-based URLs

The site now uses domain-based URLs instead of the previous page-based address structure.

🪪

Public profile revamp

Public profile viewing and presentation have been refreshed, with visitor styling kept separate from saved public profiles.

🛡️

Admin-only bot styling

Managed bot profiles can only be changed by verified admin accounts; personal profile-modal drafts are never used as bot styling data.

💬

Global chat fixes

Global chat has been repaired and updated as part of the Nexus release.

📚

Restored library icons

Missing icons on library pages 14 and 15 have been restored.

🔌

Expanded port support

The update adds support for additional ports and includes compatibility fixes.

🗃️

SQL-backed library

Library data now uses the SQL-backed service, with assets delivered as single files.

🔄

Refreshed components

Outdated components have been updated alongside the wider Nexus refresh.

WannaSmile 2.4.0 – Nexus is planned for November 13, 2026. These are the changes included in the release.
